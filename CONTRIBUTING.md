# Contributing

1. Branch from `main`.
2. Make your change in `src/`.
3. Test with a copy of the Apps Script project using each role: staff, manager and admin.
4. Update `CHANGELOG.md` and any affected runbook in `docs/`.
5. Open a pull request that describes the change and how you tested it.

Never commit real sheet IDs, folder IDs, signatures, employee data or `.clasp.json`.
