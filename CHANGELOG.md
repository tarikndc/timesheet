# Changelog

## v1.0.0-beta
- Staff monthly timesheet: leave by date range, holidays shown automatically, daily project grid
- Daily rules: 8 h maximum, minus leave or holiday on the day; weekends locked
- Submit, approve and return workflow with manager comment
- Email notifications with per-user preferences
- Official A4 PDF report with digital approval record and document reference
- Drafts for manual signature before approval
- Admin: employees (single and bulk CSV), allocations (grid and CSV), holidays, admins
- Report archive stored in Google Drive, with search by year, month, name or ID
- Reset of a submitted or approved month, with reason logged in ResetLog
- Export of approved employees to a spreadsheet tab
